# 3. Legitimate Use Cases (Why Build This)

Honest-location reporting is a defensive feature for your **own** app:

- **Employee attendance** — office check-in/out; prevents payroll fraud.
- **In-house couriers / fleets** — delivery proof, route audit.
- **Field sales** — outlet visit reports that managers can trust.
- **Insurance / surveys** — incident photo + location binding.
- **Location-based games / promos** — anti-farming.
- **Regional e-KYC / service gating** — prove the user is inside a service area.

If you are building any of these, the 5-layer model in
[04-defense-in-depth](04-defense-in-depth.md) is the blueprint.
